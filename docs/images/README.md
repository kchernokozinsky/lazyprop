# Screenshots

Screenshots referenced by the top-level [`README.md`](../../README.md). To
refresh one, replace the file keeping the same filename so the README needs no
edits.

| File | Used for | Suggested size |
| --- | --- | --- |
| `lazyprop-demo.gif` | Animated demo at the top of the README | 1200×720 |
| `main.png` | Main screen | ~1200×760 |
| `playground.png` | Playground screen | ~1200×760 |
| `yaml.png` | YAML editor | ~1200×760 |
| `about.png` | About / guides | ~1200×760 |

Tips:
- Capture in a terminal at a comfortable font size, ~100×30 cells.
- Keep aspect ratios roughly as above so the screenshots grid stays even.
- Keep the demo GIF reasonably small (a couple of MB) so it loads quickly.
